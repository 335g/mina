# WorkspaceRoot-scoped LSP sessions

LSP sessions are scoped per WorkspaceRoot — the smallest analysis unit containing the opened file (nearest `Cargo.toml`, else nearest `.git`, else the file's parent directory) — instead of one global session. The daemon keeps a map from WorkspaceRoot to session, so files from different projects (e.g. separate crates under `crates/`) each get their own rust-analyzer rooted at that project, and no session is ever reaped while the daemon lives (ADR-0005's warm-LSP fast attach). The single-session alternative was rejected: one shared server initialized with the first file's directory mis-analyzed files from later projects, and its `rootUri` did not point at a workspace root at all. Diagnostics in the snapshot remain those of the focused document only.
