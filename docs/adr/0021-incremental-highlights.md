# 構文ハイライトのインクリメンタルパースと可視範囲スナップショット

TUI が大ファイル（mina 自身の daemon.rs 等 200KB 級）で著しく遅い問題の根本原因は、**打鍵ごとの全文 tree-sitter 再パース**だった。計測（release、214KB / 4,554 行の Rust ファイル、1 打鍵あたり）:

- tree-sitter 全文再パース: **38ms**
- ハイライトクエリの再コンパイル（`Query::new`）: **20ms**
- クエリの全文走査: **19ms**
- JSON 全文往復（5ms 直列化 + 6ms 解析、wire 1.4MB のうちハイライトが ~940KB）: **11ms**

旧実装は `syntax_highlights` が checksum キャッシュを持っていたが、打鍵ごとに checksum が変わるため毎回キャッシュミス → 全文再パース + クエリ再コンパイルになっていた（計 ~90ms）。

## 決定

1. **インクリメンタルパース**: daemon は文書ごとに tree-sitter の `Tree`・`Query`・`Language` をキャッシュする。テキストが変わったら、**旧文との共通接頭辞・接尾辞の差分から `InputEdit` を求め**、`tree.edit` + インクリメンタルパースでツリーを更新する（38ms → 0.5ms）。差分は挿入・削除・置換・undo/redo・外部リロードの全編集源を同一コードで扱える — 編集範囲をコマンドごとに配線する必要がない。`Query::new`（20ms）は文書の初回パース時のみ。
2. **可視範囲スナップショット**: `StateSnapshot.highlights` は全文ではなく **可視範囲（`first_line` から `viewport_height` 行）のみ**を載せる。クエリは `set_byte_range` で窓の byte 範囲に限定する（全文走査 19ms → 窓クエリ 0.15ms @214KB、wire のハイライト分 ~940KB → 数 KB）。窓の上端を跨ぐトークン（複数行コメント・文字列）は範囲に交差するノードとして捕捉されるため、上端延長は不要（検証済み）。
   - **2026-08 追記**: 窓クエリの残存コストは (a) `collect` の byte→char 変換が窓の大きさでなく**全文**の char テーブルを毎回構築していた（O(n)、1MB で ~2ms）と (b) 窓より前のトップレベル兄弟の走査。byte→char 変換は**窓範囲限定のローカルテーブル + 窓外トークンのオーバーハング走査**に変更し、(a) を除去した。さらに daemon は (checksum, first_line, viewport_height) キーの**単一エントリ窓キャッシュ**を持ち、カーソル移動など窓が動かないコマンドでは窓クエリ自体を実行しない。1MB / 20K 行で窓クエリ 2.5-3.5ms → キャッシュヒット時 0ms。
3. 全文 JSON 往復の差分化（ADR-0006 で延期された partial snapshot）は**引き続き延期**。1+2 の適用後、打鍵あたりの同期コストは ~5ms（text clone 0.3ms + 差分 0.1ms + インクリメンタルパース 0.5ms + 窓クエリ 0.15ms + JSON 往復 ~2ms + 描画 0.6ms）になり体感不能。数百 KB 超のファイルで再び問題になったら ADR-0006 を再訪する。

キャッシュはテキストの checksum をキーに更新され、テキスト不変（カーソル移動・スクロール）ならツリーを再利用して窓クエリだけを再実行する。パース失敗時は stale ツリーで不正な範囲を出さないようキャッシュを落として空を返す。

## Consequences

- wire の意味論変更（highlights が全文 → 可視範囲）→ PROTOCOL_VERSION 3 → 4
- TUI の描画は窓内の範囲しか使わないため変更不要（昇順・非重複の不変条件は窓の部分集合でも保たれる）
- headless クライアントが `GetState` で受け取るハイライトは可視範囲のみになる（エージェントは全文テキストを既に受け取っており、ハイライト分析が必要になったら範囲指定 API を追加する）
- 可視範囲の行数を超える巨大なトップレベルノード（巨大 impl 等）の中に窓がある場合、クエリ走査はそのノードの先頭から走る（全文よりは小さいが、窓だけで済まない）。問題になったら上端の行数キャップを足す
