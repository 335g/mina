# Undo groups close on leaving Insert and on client disconnect

An UndoGroup — a set of Transactions reverted by a single undo — spans exactly one Insert session: it opens when the editor enters Insert mode and closes when it leaves Insert (to Normal or Select), or when the owning Client disconnects while in Insert (which also returns the editor to Normal). The alternative — closing only on Insert→Normal — leaves the group open through Select transitions and, worse, through client churn: because the daemon and its History are persistent (ADR-0005), an unclosed group merges edits from different sessions into one undo unit, silently destroying undo granularity (edits from a previous session vanish on a single undo). Connection-scoped groups were rejected for v1 — under the effectively-one-client model a daemon-side boundary is sufficient; a future multi-client model can revisit by making group scope explicit in the protocol.
