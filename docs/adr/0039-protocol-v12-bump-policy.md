# プロトコル v12: bump 方式で一括導入（分離 + 活動可視化）

接続別フォーカス（ADR-0037）と活動可視化（ADR-0038）のプロトコル拡張は、**PROTOCOL_VERSION を 11 → 12 に上げ、新ソケット `minae-12.sock` に新デーモン + 新クライアント（minad / minas / minae 同梱）で一括導入**する。これは既存の bump 慣習（v5〜v11 の全履歴: wire が変わったら必ず version を上げる）の延長であり、新旧は別ソケットで物理的に交わらない — ネゴシエーション不要・「古いビルドが新プロトコル項目を黙殺する」危険（issue #27）が構造的に起きない。

- **移行**: 今回の変更ではデーモン状態の**リセットを許容**（引き継ぎなし・開き直し。運用メモ: バージョン更新時は常駐デーモンの再起動を推奨）。一般的なバージョン更新方針としては、旧デーモンが旧ソケットに残る**併存を許容**する（自動で古デーモンを殺さない — 入力を失う恐れ）
- **テスト**: 旧 wire テストを v12 形状へ更新（旧形状テストの並行維持はしない）
- **GetServerInfo**: 現状のまま温存（拡張・廃止なし。偶然の違うバージョン接続の検知用の安全機構として残す。「バージョン番号の明示」への拡張は将来再検討と留保）

Status: accepted

## Considered Options

- additive 方式（同一ソケット・同一バージョンで新フィールド追加のみ、旧クライアントは未知フィールド無視 + レガシーモード）: 同一デーモン上の新旧混在は同梱リリース・pre-1.0 のこのプロジェクトに需要がなく、デーモンの二重モード + クライアントのフォールバック + 黙殺リスク管理を抱える → 棄却
