# Open は非通常ファイルと巨大ファイルを拒否する

minae は通常ファイルでないパス (ディレクトリ、/dev/zero などのデバイス、FIFO) と 16 MiB を超えるファイルのオープンを拒否し、エディタの状態に触れずにスナップショットのステータスで "file too large" / "cannot open" を報告する。デーモンは読み取り前にメタデータ (is_file + size) を検査する。根拠: v1 のコマンドごとの完全スナップショット IPC と全文 LSP 同期 (ADR-0006) は、上限に関係なく数百 MiB のファイルを実用不能にする。また無制限の読み取りは OOM とハングの経路である — /dev/zero は永遠に読み、FIFO は永遠にブロックし、増え続けるログはメモリを膨張させる。上限は単純な定数であり、diff スナップショット (v1 の非目標) が導入され大容量ファイルモードが実現可能になったときに再検討する。コマンドラインも同様に制限される (1 MiB) ので、改行のないストリームがデーモンの読み取りバッファを無制限に成長させることがない。
